# Лабораторная работа №6: Нейрон с сигмоидной функцией активации

## 📋 Описание

Реализация класса `Neuron` с сигмоидной функцией активации и функцией потерь LogLoss для решения задач бинарной классификации. Тестирование на двух датасетах и сравнение со sklearn.

## 📂 Файлы в проекте

- **`lab6_solution.ipynb`** - основной ноутбук с решением и всеми экспериментами
- **`lab6_report.md`** - полный отчет по лабораторной работе (официальный формат)
- **`apples_pears.csv`** - датасет с яблоками и грушами (2 признака)
- **`voice.csv`** - датасет с голосовыми характеристиками (20 признаков)
- **`practice_perceptron.ipynb`** - пример с перцептроном (для справки)
- **`practice_neuron_logloss.ipynb`** - практика с нейроном (для справки)

## 🎯 Результаты

### Датасет Apples & Pears
- **Train Accuracy:** 93.5%
- **Test Accuracy:** 91.0%
- **Final Loss:** 0.249
- Сравнение со sklearn: -1.5% (небольшое отставание)

### Датасет Voice
- **Train Accuracy:** 97.43%
- **Test Accuracy:** 97.32%
- **Final Loss:** 0.093
- Сравнение со sklearn: -0.16% (практически идентично!)

## 🔬 Ключевые особенности реализации

1. **Сигмоидная функция активации:** `σ(x) = 1 / (1 + e^(-x))`
2. **Функция потерь LogLoss** (Binary Cross-Entropy)
3. **Batch Gradient Descent** для обучения
4. **Полная векторизация** операций с NumPy
5. **Детальная визуализация** результатов
