## 2. Теоретическая основа

### 2.1. Сигмоидная функция активации

Сигмоидная функция (логистическая функция):

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

**Свойства:**
- Область значений: (0, 1)
- Гладкая и дифференцируемая
- Выход можно интерпретировать как вероятность принадлежности к классу

### 2.2. Функция потерь LogLoss

Логарифмическая функция потерь (Binary Cross-Entropy):

$$Loss(\hat{y}, y) = -\frac{1}{n} \sum_{i=1}^n \left[y_i \log(\hat{y_i}) + (1 - y_i) \log(1 - \hat{y_i})\right]$$

где:
- $\hat{y_i} = \sigma(w \cdot x_i + b)$ - предсказание модели
- $y_i \in \{0, 1\}$ - истинная метка класса
- $n$ - количество объектов

**Преимущества LogLoss для сигмоиды:**
- Устраняет проблему затухающих градиентов (в отличие от MSE)
- Штрафует за уверенные неправильные предсказания
- Градиент имеет простой вид

### 2.3. Градиентный спуск

Градиенты функции потерь:

$$\frac{\partial Loss}{\partial w} = \frac{1}{n} X^T (\hat{y} - y)$$

$$\frac{\partial Loss}{\partial b} = \frac{1}{n} \sum_{i=1}^n (\hat{y_i} - y_i)$$

Правило обновления параметров:

$$w^{new} = w^{old} - \alpha \cdot \frac{\partial Loss}{\partial w}$$

$$b^{new} = b^{old} - \alpha \cdot \frac{\partial Loss}{\partial b}$$

где $\alpha$ - скорость обучения (learning rate).

## 3. Описание реализации

### 3.1. Класс Neuron

Реализован класс `Neuron` со следующими методами:

1. **`__init__(w, b)`** - инициализация весов и смещения
2. **`activate(x)`** - применение сигмоидной функции активации
3. **`forward_pass(X)`** - прямой проход для вычисления предсказаний
4. **`backward_pass(X, y, y_pred, learning_rate)`** - обратный проход для обновления весов
5. **`fit(X, y, num_epochs, learning_rate)`** - обучение модели
6. **`predict(X, threshold)`** - предсказание классов

### 3.2. Вспомогательные функции

- `sigmoid(x)` - сигмоидная функция с защитой от overflow
- `logloss(y_pred, y)` - вычисление функции потерь
- `plot_decision_boundary()` - визуализация разделяющей границы
- `plot_loss_history()` - график изменения функции потерь
- `plot_confusion_matrix()` - визуализация матрицы ошибок

### 7.1. Ключевые наблюдения

1. **Корректность реализации:**

   - Результаты на уровне sklearn подтверждают правильность алгоритма

   - На Apples & Pears работает и без нормализации
   - Разные масштабы признаков требуют нормализации

3. **Размерность и качество:**
   - Больше признаков → больше информации → выше accuracy
   - Voice (20D): 97.3% vs Apples & Pears (2D): 91.0%
   - Но риск переобучения выше при большой размерности

4. **LogLoss vs MSE:**
   - LogLoss хорошо работает с сигмоидой
   - Нет проблемы затухающих градиентов
   - Стабильная сходимость

5. **Интерпретируемость:**
   - Веса показывают важность и направление влияния признаков
   - Можно понять логику принятия решений
   - Важно для практического применения

### 7.2. Преимущества разработанной модели

- ✅ Простота и понятность кода
- ✅ Полный контроль над процессом обучения
- ✅ Легко модифицировать и расширять
- ✅ Образовательная ценность
- ✅ Результаты на уровне промышленных решений
- ✅ Быстрая работа на небольших данных

### 7.3. Ограничения

- ⚠️ Только бинарная классификация (не multi-class)
- ⚠️ Batch gradient descent - медленно на больших данных
- ⚠️ Нет регуляризации - риск переобучения
- ⚠️ Фиксированная скорость обучения - может быть неоптимальной
- ⚠️ Нет автоматической остановки обучения

### 7.4. Возможные улучшения

1. **Регуляризация (L1/L2):**
   - Добавить штраф за большие веса
   - Предотвратить переобучение
   - Улучшить обобщающую способность

2. **Mini-batch Gradient Descent:**
   - Ускорить обучение на больших данных
   - Снизить требования к памяти
   - Добавить стохастичность для избегания локальных минимумов

3. **Адаптивная скорость обучения:**
   - Learning rate scheduling (decay)
   - Адаптивные методы (Adam, RMSprop)
   - Быстрая сходимость

4. **Early Stopping:**
   - Валидационная выборка
   - Остановка при переобучении
   - Экономия времени обучения

5. **Кросс-валидация:**
   - Более надежная оценка качества
   - Подбор гиперпараметров
   - Снижение влияния разбиения данных

6. **Multi-class классификация:**
   - Softmax вместо сигмоиды
   - Cross-Entropy Loss
   - Один-против-всех или один-против-одного

### 7.5. Практические рекомендации

1. **Выбор скорости обучения:**
   - Начинать с 0.01-0.1
   - Слишком большая → неустойчивость
   - Слишком малая → медленная сходимость

2. **Количество эпох:**
   - Наблюдать за графиком Loss
   - Остановиться при стабилизации
   - 1000-5000 эпох обычно достаточно

3. **Предобработка данных:**
   - Всегда стандартизировать при разных масштабах признаков
   - Проверять на наличие выбросов
   - Удалять константные признаки

4. **Оценка качества:**
   - Не только accuracy - смотреть precision/recall
   - Использовать confusion matrix
   - Проверять на несбалансированных данных
